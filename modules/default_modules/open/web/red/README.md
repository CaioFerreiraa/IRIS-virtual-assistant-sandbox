# Página vermelha

Abre a rota local `http://127.0.0.1:4101/web/vermelho` no navegador padrão.

## O que pode ser verificado

- execução legada do tipo `GET`;
- retorno estruturado com a chave `opened`;
- registro de sucesso ou erro no histórico;
- abertura de uma página HTML com fundo vermelho.

## Dependência

O servidor de `modules/default_modules/open/web/main.py` precisa estar em execução na porta 4101.
