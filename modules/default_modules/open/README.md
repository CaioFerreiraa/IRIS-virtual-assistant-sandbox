# Abrir

Módulo organizacional para ações que abrem recursos locais ou páginas.

## Submódulos atuais

- `App`: pesquisa e abre itens da Área de Trabalho;
- `Web`: organiza duas páginas locais de demonstração.

## O que pode ser verificado

- módulo pai não executável com filhos executáveis;
- hierarquia mista entre runtime Python e abertura de URL;
- navegação por breadcrumb e sidebar.
